# 轻购电商平台 Demo（buy-you-want-demo）

一个 C 端电商平台跨端 Demo，用于验证三项核心技术能力：

- **跨端开发**：React Native + TypeScript 一套代码覆盖 iOS / Android
- **双 Token 鉴权**：Access Token + Refresh Token，实现无感刷新登录态
- **轻量埋点 SDK**：自研零依赖、KB 级埋点 SDK

后端：NestJS（Node.js）+ MySQL
